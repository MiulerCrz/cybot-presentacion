ARCHIVOS
- index.html: contenido.
- style.css: apariencia futurista.
- script.js: efectos y año automático.

PONER LAS IMAGENES
Guarda las imágenes que compartiste dentro de assets con estos nombres:
1) cybot-hero.jpg: imagen horizontal de CYBOT.
2) cybot-action.jpg: robot de cuerpo completo en movimiento.
La tercera imagen vertical queda disponible como referencia. Si tus archivos son JPEG/PNG, usa su extensión real en index.html o conviértelos con Paint > Guardar como > Imagen JPEG.

PROBAR
1. Descomprime CYBOT-Web.zip.
2. Abre VS Code > File > Open Folder > selecciona CYBOT-Web.
3. Verifica que index.html, style.css y script.js estén juntos en la raíz.
4. Abre index.html en el navegador. Los botones de teléfono, WhatsApp e Instagram ya funcionan.

PUBLICAR EN VERCEL
1. Crea un repositorio nuevo en GitHub, por ejemplo cybot-presentacion.
2. Sube los archivos de dentro de CYBOT-Web (no una carpeta CYBOT-Web adicional).
3. En la raíz del repositorio deben verse index.html, style.css, script.js y assets/.
4. En Vercel elige Add New > Project > importa el repositorio > Deploy.
5. No cambies Root Directory si index.html está en la raíz.
6. Pulsa Visit y prueba el enlace desde tu teléfono.
